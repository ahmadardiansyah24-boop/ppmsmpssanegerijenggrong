# GENERATOR PPM

Perencanaan Pembelajaran yang Lengkap, Menarik, dan Siap Digunakan.

## Jalur
- **DIKNAS** — Kurikulum Merdeka + Pembelajaran Mendalam + Taksonomi SOLO + Asesmen.
- **KEMENAG** — Kurikulum Madrasah + Pembelajaran Mendalam + KBC + Taksonomi SOLO + Asesmen.

## Target aplikasi
- Dashboard profesional mengikuti desain referensi.
- Generator PPM bertahap.
- Quality Gate untuk konsistensi CP → TP → aktivitas → SOLO → asesmen.
- Theme Studio: Modern, Islami, Cartoon, Minimalis, dan custom warna.
- Gambar/ilustrasi untuk cover dan LKPD.
- Preview A4 dan tahap berikutnya PDF/Word.

## Deployment
Project ini adalah web statis pertama sehingga dapat diimpor langsung ke Vercel dari repository ini.
